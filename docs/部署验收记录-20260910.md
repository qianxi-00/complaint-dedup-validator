回滚该结构操作时，由维护人员停服务并确认目标表名不存在后执行：

```sql
ALTER TABLE complaint_legacy_20260910.work_order_cannot_links SET SCHEMA public;
```

完整数据库备份、运行目录备份、旧 compose 和旧镜像标识保存在：

